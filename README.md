# One Pixel Home

NASA Space Apps Challenge 2026 — Space Mission Design Game.

A browser game where 1–4 players design, launch and simulate an Earth-observation CubeSat mission. Every consequence is explained and traceable to a source.

- Design spec: [docs/engine-spec.md](docs/engine-spec.md)
- Project conventions: [CLAUDE.md](CLAUDE.md)

Development starts at the event kickoff. This repository currently holds planning documents only.
